## Key things I learned

- Lists store ordered items, and indexing starts at 0, so `first_half[4]` is the fifth item.
- f-strings (for example `f"The first color is {colors[0]}"`) combine text and variables in a print statement.
- Python is case sensitive, so `x` and `X` are different variables.
- A module must be imported before its functions can be used.

## How to run

